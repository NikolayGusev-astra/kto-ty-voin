# kto-ty-voin - «Кто ты, воин?»

Hermes Agent skill: короткое интервью, после которого агент знает, чем человек
занимается, какие инструменты у него уже есть и где болит, - и подбирает ему
скиллы, MCP и инструменты под эти задачи. Вместо ответа на вопрос «зачем мне
агент» скилл превращает этот вопрос в разговор.

## Отсылка

Название - из «Трои» (2004). Мальчик-герольд спрашивает у огромного бойца,
вышедшего против греческого отряда: «Кто ты, воин?» Тот отвечает одним словом:
«Ахиллес» - и этого достаточно, чтобы стало ясно, чем закончится бой.

Скилл решает обратную задачу: прежде чем агент начнёт отвечать, чем он полезен,
он должен понять, кто перед ним. Не «второй мозг» и не «личный советник» - а
конкретный человек с конкретными рутинами. Сварщику нужны таблицы электродов,
швее - себестоимость платья, бухгалтеру - сроки отчётности. Вопрос герольда
здесь работает буквально: сначала узнаём, кто ты, потом говорим, чем можем быть
полезны.

## Что делает

Процедура из шести шагов:

1. Опрос - максимум 3 раунда по 3-4 вопроса, только о фактах жизни: рутины,
   данные, инструменты, раздражения, границы. Вопросов «какая у вас цель» нет
   сознательно: человек, которому нужен агент, обычно не знает ни своих целей в
   терминах агента, ни того, что агент вообще умеет.
2. Витрина возможностей - 3-5 классов возможностей агента, каждый показан
   одной сценой на ответах самого человека. Распознавание вместо генерации:
   реагировать на примеры можно, формулировать цель в вакууме - нет.
3. Карта болей и гипотеза цели - цель формулирует агент, человек подтверждает
   или правит.
4. Подбор - только из живых каталогов окружения пользователя (Skills Hub,
   локальные скиллы его профиля, MCP), с обязательным inspect и security scan
   перед установкой.
5. Отчёт - файл с таблицей «боль, инструмент, как выглядит в вашем дне, статус»,
   планом установки и честным списком «что сознательно не ставим».
6. Демо - одна реальная задача пользователя прогоняется на подобранном наборе.
   Демо на выдуманном примере не считается.

## Почему он такой

Скилл вырос из пяти чистотных прогонов на тестовых персонах: учительница с
недоверием к ИИ и жёсткой границей «данные детей наружу не отправлять»,
мужчина после 30 лет заключения, изучающий Java без единого аккаунта и банковской
карты, швея с выставками в Париже, бухгалтер с персональными данными клиентов,
фермер с Windows 7. Каждая находка от контролёров качества вшита в правила:

- вопрос «какая у вас цель» убран - он воспроизводит ошибку гайдов, против
  которых скилл написан (распознавание вместо генерации);
- граница «данные наружу не отправлять» проверяется и против самого агента:
  где исполняется модель, в которую уйдут тексты пользователя;
- подбор - только из каталогов окружения пользователя: инструменты из среды
  самого агента не рекомендуются, у человека их нет;
- провенанс: каждая рекомендация несёт точную команду проверки из этого же
  сеанса; фантазированный провенанс бракует отчёт целиком;
- режим «агент не встанет на вашу машину»: ручной путь сейчас и план на
  будущее, без платных обновлений ОС и без молчания о несовместимости;
- если агенту здесь нечего делать (хватит Excel) - скилл прямо об этом скажет.
  Отказ от агента - валидный результат опроса.

Методология тестирования субагентами на чистом окружении - отдельный приём:
изоляция сессии субагента не изолирует его окружение, и «живой каталог»
тестовой машины выдаёт ложные рекомендации.

## Структура

```
kto-ty-voin/
  SKILL.md                         - процедура: опрос, витрина, подбор, отчёт, демо
  references/
    provenance.md                  - чеклист проверки фактов при подборе
    interview-methods.md           - правила интервью: Mom Test, JTBD, приоры
    changelog.md                   - история версий (для сопровождающих)
```

## Установка

```
hermes skills install <идентификатор из Skills Hub>
```

или вручную: скопировать каталог в папку skills вашего профиля Hermes Agent.
Нужен Hermes Agent; интерфейс команд hermes skills сверяйте со своей
версией (hermes skills --help).
