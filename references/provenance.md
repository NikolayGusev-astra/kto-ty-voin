# Чеклист провенанса (проверка фактов при подборе)

Каждый кандидат в отчёте - одна строка: какую боль закрывает и ЧЕМ проверен.
«Проверен» одним словом не считается. Правила:

## Что считать проверкой
- Только реально выполненные в этом сеансе команды. Формулировка «поиск X не дал» врёт, если поиска не было.
- Веб-поиск не равен «живому заходу на сайт».
- Утверждение о наличии страницы - только если она открылась в этом сеансе: ссылка из оглавления открытием не считается.
- Результат цитировать как есть, включая цепочку редиректов (301 -> итоговый код), не сворачивая несколько заходов в один.
- Фантазированный провенанс бракует отчёт целиком.

## Хаб и скиллы
- Запрос, отклонённый CLI (например двухсловный), повторить переформулированным (одно слово) до результата: упавший поиск не засчитывается.
- Факт о хабе, использованный даже для обоснования отказа («интеграций нет», «инструментов обезличивания нет»), требует того же прогона: «отклоняемый» не значит «непроверяемый».
- Множественное число («прочитал их описания») - только для реально открытых скиллов; для остальных - «не проверено».
- inspect, вернувший только карточку без SKILL.md, не делает скилл рекомендацией - максимум кандидат с пометкой «инструкция недоступна в каталоге».
- community-скилл без зафиксированного security scan - статус «есть в каталоге, не проверено»; уровень доверия каталога указывать в отчёте.

## Сайты и скачивание
- Страница скачивания - тоже внешний факт: перед строкой «сайт X, ветка Y (версия Z)» прогнать саму витрину загрузок и дать точный URL инсталлятора из прогона. Release-notes не витрина: «still»-ветка может уже уйти в архив.
- Бесплатность источника (локального или облака) проверяется страницей Pricing: не открылась в сеансе - «не проверено».
- Источник скачивания локальной модели проверяется как обычный сайт, включая «нужен ли аккаунт».

## Возможности агента и границы
- Возможности самого агента (vision, cron, доставка в мессенджер) - тот же внешний факт: прогон или документ этого сеанса, иначе «не проверено».
- Отказ по границе обосновывать только проверенной частью факта; непроверенная часть (цена, условия) - отдельной строкой с пометкой.
- Инструмент, легализующий запрещённый пользователем поток (обезличивание с отправкой в облако при запрете «данные наружу не отправлять»), - только условная опция на случай пересмотра границы, не рекомендация.
